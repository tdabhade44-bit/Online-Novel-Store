# NovelSite – Online Novel Store

## About
NovelSite is a web-based online book store project where users can explore novels and access book-related information. The project is developed using PHP and MySQL.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Features
- Browse novels
- View novel details
- User registration and login
- Database connectivity
- Organized novel categories

## Database
The project uses a MySQL database named `novels_`.

## How to Run
1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Import the project database using phpMyAdmin.
5. Update the database connection settings if required.
6. Open the project in your browser using `http://localhost/novelsite/`.

## Project Purpose
This project was developed to practice web development using PHP and MySQL and to understand database connectivity in an online book store application.
